# Portfolio — Vanessa Valendhita Santoso

Situs portofolio statis menggunakan HTML dan CSS, tanpa framework atau proses build.

## Struktur

- index.html: isi dan susunan halaman.
- css/style.css: tampilan desktop dan mobile.
- assets/images/: tempat gambar proyek bila diperlukan.

## Sebelum dipublikasikan

1. Ganti placeholder proyek dan riset dengan informasi yang boleh dibagikan.
2. Ganti alamat email contoh dengan email profesional.
3. Periksa judul, status paper, kontribusi, dan tautan.
4. Jangan unggah data sensitif atau materi proyek yang belum boleh dipublikasikan.

## GitHub Pages

Untuk alamat https://vanessavlnn.github.io/, nama repository harus vanessavlnn.github.io. Unggah isi folder ini ke root branch main, lalu buka Settings > Pages. Pilih Deploy from a branch, branch main, folder /(root), lalu simpan.
